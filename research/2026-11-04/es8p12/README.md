# NUMERIA ES8-P12 — formalização finita (04/11/2026)

Este módulo formaliza as 16 igualdades de exatidão da regra racional fechada de Newton–Cotes (com seis pesos negativos) e os lemas abstratos de positividade que resultam de uma fatoração racional LDL com pivôs positivos e transformação injetiva.

Compilar: cd NUMERIA_E8K_FORMAL && lake env lean ES8P12.lean

O escopo NÃO inclui inclusão nodal digama/zeta, erro integral de Cauchy, identidade das matrizes concretas N=6/8/10 com a fatoração abstrata, positividade universal de Weil ou RH.
