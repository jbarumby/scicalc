# NUMERIA ES8-P11 — Lean 4 partial mechanization

This branch adds ES8P11.lean, compiled by a dedicated GitHub Actions workflow.
It proves (subject to successful compilation) rational interval addition/subtraction,
signed interval scaling, finite weighted sum inclusion, exact rational improvement
factors of ES8-P10, and signs of the rational B2/B4 correction terms.

**Not proved in Lean:** the digamma/Hurwitz analytic identity, infinite
Euler–Maclaurin error theorem, Lagrange remainder / Cauchy bound, the
identification of K16 with an integral of a degree-16 absolute polynomial,
the 768000 individual nodal inclusions, full interval LDL certificates,
universal Weil positivity, and the Riemann hypothesis.
