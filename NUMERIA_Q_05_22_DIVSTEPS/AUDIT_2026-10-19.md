## Achados detalhados

### A. Procedência

As execuções históricas usaram workflow que apontava para upstream `main` e não guardava o SHA usado. O workflow no branch foi atualizado para fixar `64b5a13aa249f1360846657392e6c66817b26d0f` e registrar SHA do circuito, contrato, lockfile, Python, uv, log e relatório JSON nas próximas execuções. A mudança não prova retroativamente a revisão usada nas execuções anteriores.

### B. Axiomas Lean

Em `Hddivsteps590/Certificate.lean`, `example590_par` é provado por `native_decide`. `example590` é transferido para a especificação serial via `certEmptyPar_eq`. `Main.lean` imprime as dependências de axiomas dos teoremas públicos. A dependência adicional de `native_decide` para os teoremas de limite é deliberada e documentada upstream. Não é, isoladamente, evidência de erro matemático; impede, porém, a afirmação de que os limites foram verificados exclusivamente pelo kernel. Auditoria independente de todas as saídas de `#print axioms` e alternativa kernel-only continuam abertas.

### C. Quatro falhas

O avaliador só registrou contagens agregadas (4 saídas erradas, 3 sinais errados, 4 falhas agregadas); as três ocorrências de sinal estão sobrepostas às quatro saídas erradas. O README upstream informa agenda de 533 passos e orçamento para caminhadas raras mais longas. Nossa amostra de 100.000 entradas não encontrou caminhada acima de 532. Como a sequência de entrada do avaliador é diferente e as entradas falhas não foram registradas, a hipótese de excesso de passos é plausível, mas não comprovada. Não atribuir causa até reproduzir as entradas exatas.

### D. Testes e tempo

Os testes clássicos existentes passaram 3/3 nos logs CI examinados. Os cinco testes adicionais de referência Python passaram localmente nesta auditoria. A amostragem de 100.000 entradas demorou aproximadamente 10,1 s neste ambiente, com média 516,83705 e máximo 532.

O patch fornecido para revisão contém uma discrepância: o texto declara 134 s, enquanto `report.json` registra 95,26365566253662 s. Os logs CI disponíveis mostram o executor de referência Python puro; não confirmam uma reexecução local com kernel C. Não reportar a duração com kernel C como verificada até anexar log e reconciliar os tempos.

### E. Comparação de recursos

Baseline confirmado: 4.006.673 Toffoli, 15.391.673 Clifford, 935 qubits de pico, custo Toffoli × qubits 3.746.239.255. Estimativa nominal de T: 28.046.711 se se assumir 7 T por Toffoli; não é contagem após síntese. A implementação NUMERIA-Q comparável, profundidade T e qubits lógicos continuam sem medição; deltas percentuais permanecem N/D.
